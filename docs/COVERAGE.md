## Verification and measurement contract

Each play's verification must record the actual inputs, relevant revision, execution identity/environment, observed success/failure, evidence location and remaining gap. A check of links or frontmatter cannot mark a service capability verified. The source's thirteen measurement blocks and six sections without independent metrics are explicitly listed in [MEASURES.md](MEASURES.md); no metric is fabricated to fill a blank.

## Source interpretation boundaries

- Source control objectives are retained as source requirements, not silently claimed as implemented. The current user-approved scope defers enforcement; real identities and decisions are never invented.
- Example thresholds, safe-command patterns, company policy snippets, model versions and managed JSON are not universal configuration requirements.
- Source alternatives remain alternatives: repository versus legacy authority; managed review versus CI action; supported model-access providers; scheduled offline evals versus continuous execution where the source allows it.
- Hosted Security, Tag and other operational plays remain in the full source inventory but are deliberately deferred. A local reviewer is not a substitute implementation of those services. The knowledge stores under `docs/adr/`, `docs/incidents/`, `docs/security/` and `docs/solutions/` are the durable records those plays would eventually write into; today they are filled only by an engineer confirming an offer from a skill.
- The source's visual adoption graph is preserved separately from written prerequisites and execution handoffs; discrepancies are not silently corrected.
- No company customisation, Kiro file convention, new approval committee, or risk-tier redesign has been added.

This matrix accounts for the full source, not delivery of every capability. The [active implementation plan](../IMPLEMENTATION_PLAN.md) and [future work](../FUTURE_WORK.md) determine what to build now versus later; the original external-dependency labels must not be used to block current artifact work.
