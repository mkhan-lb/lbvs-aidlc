# lbvs-aidlc plugin

Generated by `python3 scripts/build_plugin.py` from the repo-template sources; do not edit by hand.

Skills are namespaced `/lbvs-aidlc:<skill>` (`/lbvs-aidlc:aidlc <change-id>` starts a change). Agents: `lbvs-aidlc:aidlc-verifier`, `lbvs-aidlc:aidlc-repo-scout`. Hooks: project-mode line at session start and reproduction-test protection while `.aidlc/fix/*.json` exists in the project.

The plugin does not ship a `CLAUDE.md`; run `/lbvs-aidlc:aidlc-onboard` or `/init` in the adopting repository. Shared workflow docs live under `docs/` inside the plugin and are referenced via `${CLAUDE_PLUGIN_ROOT}`.
