# lbvs-aidlc plugin

Generated by `python3 scripts/build_plugin.py` from the repo-template sources; do not edit by hand.

Skills are namespaced `/lbvs-aidlc:<skill>` (`/lbvs-aidlc:lbvs-aidlc <change-id>` starts a change; `/lbvs-aidlc:lbvs-aidlc-init` sets a repository up). Agents: `lbvs-aidlc:lbvs-aidlc-conventions-checker`, `lbvs-aidlc:lbvs-aidlc-design-reviewer`, `lbvs-aidlc:lbvs-aidlc-repo-scout`, `lbvs-aidlc:lbvs-aidlc-test-critic`, `lbvs-aidlc:lbvs-aidlc-threat-modeler`, `lbvs-aidlc:lbvs-aidlc-verifier`. Hooks: project-mode line at session start and reproduction-test protection while `.aidlc/fix/*.json` exists in the project. The helper is reachable as `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/aidlc.py" <subcommand>`; `conventions` uses the bundled `templates/conventions/`.

The plugin does not ship a `CLAUDE.md`; run `/lbvs-aidlc:lbvs-aidlc-onboard` or `/init` in the adopting repository. Shared workflow docs live under `docs/` inside the plugin and are referenced via `${CLAUDE_PLUGIN_ROOT}`.
